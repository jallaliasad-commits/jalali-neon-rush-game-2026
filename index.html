About the Game

Welcome to Neon Rush, a small arcade game created as the JALALI.EDITS game development project.

Your mission is simple: control your neon player, dodge incoming obstacles, survive as long as possible, and increase your score.

Built using HTML, CSS and JavaScript. Designed to run directly in your web browser.
